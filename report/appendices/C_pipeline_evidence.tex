\chapter{Pipeline evidence}

\section{Tham số Jenkins khuyến nghị}

Khi ứng dụng đã deploy lên EKS và web URL reachable, pipeline có thể chạy với các tham số:

\begin{lstlisting}
RUN_ZAP=true
DEPLOY_TARGET_URL=http://<node-external-ip>:30006
ZAP_TARGET=http://<node-external-ip>:30006
RUN_ARGO_HEALTH_CHECK=true
KUBECONFIG_CREDENTIAL_ID=jenkins-argocd-kubeconfig
GITOPS_BRANCH=gitops-testing
\end{lstlisting}

\section{Diễn giải khi bảo vệ}

Khi trình bày pipeline, không nên chỉ nói ``pipeline chạy xanh''. Cần giải thích pipeline chứng minh điều gì:

\begin{itemize}
  \item SAST/SCA giúp phát hiện lỗi mã nguồn và dependency trước khi build image.
  \item Trivy/Checkov/Terraform validate giúp kiểm tra artifact và hạ tầng.
  \item Docker build và image scan giúp đảm bảo image tạo ra có thể triển khai và đã được quét.
  \item GitOps update giúp trạng thái deploy có lịch sử trong Git.
  \item Argo CD health chứng minh cluster đã reconcile về trạng thái mong muốn.
  \item Smoke test chứng minh app sau deploy reachable.
  \item ZAP DAST kiểm tra ứng dụng đang chạy và tạo report bảo mật động.
\end{itemize}
