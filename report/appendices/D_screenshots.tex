\chapter{Danh sách hình ảnh minh họa}

\section{Ảnh UI đã sử dụng}

Các ảnh trong \code{report/images/screen} được sử dụng cho phần triển khai ứng dụng và bằng chứng giao diện:

\begin{itemize}
  \item \code{dashboard.png}: dashboard.
  \item \code{document.png}: danh sách và tổng quan tài liệu.
  \item \code{approvals.png}: phê duyệt.
  \item \code{audit.png}: audit log.
  \item \code{security.png}: security posture.
  \item \code{accessreview.png}: rà soát quyền truy cập.
\end{itemize}

\section{Ảnh UI nên bổ sung}

Để mô tả đầy đủ hơn các luồng chính của frontend, có thể bổ sung:

\begin{itemize}
  \item Màn hình đăng nhập qua Keycloak.
  \item Form tạo tài liệu và upload file.
  \item Chi tiết tài liệu, version history và workflow timeline.
  \item Evidence Center và retention policy.
  \item Thông báo lỗi khi người dùng bị policy từ chối download.
\end{itemize}

\section{Ảnh cần bổ sung trước khi nộp}

Trước khi nộp bản cuối, nên bổ sung các ảnh pipeline/evidence sau:

\begin{itemize}
  \item Jenkins stage view của build mới nhất.
  \item SonarQube project dashboard.
  \item Dependency Check report.
  \item Trivy image scan log/report.
  \item Checkov/Terraform validate log.
  \item Docker Hub hoặc registry image tags.
  \item GitOps commit cập nhật Helm values.
  \item Argo CD applications Synced/Healthy.
  \item ZAP HTML report summary.
  \item Grafana workload dashboard.
  \item Loki query log namespace \code{docvault}.
\end{itemize}

Khi chụp ảnh, cần che hoặc loại bỏ token, secret, kubeconfig, IP nhạy cảm và thông tin tài khoản không dùng cho demo công khai.
