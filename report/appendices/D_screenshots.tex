\section{Yêu cầu bảo mật đối với ảnh}

Trước khi đưa ảnh vào báo cáo, phải loại bỏ hoặc che các thông tin sau:

\begin{itemize}
  \item password, token, secret value, private key và credential ID có tính nhạy cảm;
  \item nội dung kubeconfig, JWT, cookie, presigned URL và object key thực;
  \item dữ liệu tài liệu của người dùng;
  \item thông tin AWS không cần thiết như account ID đầy đủ hoặc ARN nhạy cảm;
  \item địa chỉ quản trị nội bộ không phục vụ giải thích kiến trúc.
\end{itemize}
